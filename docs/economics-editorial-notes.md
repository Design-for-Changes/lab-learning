# 経済学入門の編集方針

2026-09-15。参考記事は蘆澤雄亮「3-07 デザインのミクロとマクロ」。読者が標準的な経済学の基礎を学ぶことを主目的とする。ゲーム理論・ナッシュ均衡は扱わない。ユーザーの指示により、デザインとの接続を扱う章は設けず、研究アプローチまでの5章とする。

## 章の順番

1. 経済学の基本：希少性、配分・分配、機会費用、限界分析、ミクロとマクロ。
2. 経済学の成立と展開：古典派、マルクス、限界革命、新古典派、フリッシュ、ケインズ、戦後のケインズ派、マネタリズム、新しい古典派、RBC、ニューケインジアン、新しい新古典派総合、実証研究、日本のリフレをめぐる議論。
3. ミクロ経済学：家計と企業、需要・供給、弾力性、費用、市場構造、外部性・公共財。
4. マクロ経済学：循環、GDP・物価・雇用、倹約のパラドックス、財政・金融政策、成長。
5. 経済学の研究アプローチ：理論、測定・実証、因果推論、実験・自然実験、構造モデルと政策評価。

歴史は人物名の列挙にせず、年表示側に転換点と主要概念、本文側に問い・説明・次につながる関係を置く。初出年とリンク先の後年版を混同しない。限界革命の三者や各学派を一つの立場として扱わず、後の理論がすべてを置き換えたとも書かない。

研究アプローチは対象の区分（ミクロ／マクロ）と調べ方（理論／実証）を分ける。相関・予測・因果効果・政策シミュレーションを同じ証拠として扱わない。差の差の例は架空で、平行トレンドと比較地域への波及などを本文に明記する。Card・Kruegerの実際の研究結果の数値と混同しない。

ケインズ以後は、具体例と「何を引き継いだか」を併記する。戦後のケインズ派（新古典派総合）とニューケインジアンを区別する。リフレは学派名ではなく、デフレ・需要不足からの回復を目指す政策の考え方として扱う。ニューケインジアンやマネタリズムと同義にしない。リフレで重視される経路を示し、効果の実証とは区別する。年代の重なる学派・政策論は、互いを一斉に置き換えたものとして描かない。

## 数値例と検証

- 予算：ノート300円、コーヒー200円。予算は1,200円／1,800円。整数単位と使わずに残る金額を表示。
- 市場：競争市場の架空の直線モデル。需要側の逆需要は600＋需要変化−4Q、供給側は120＋費用変化＋4Q。選択価格の点と均衡を区別する。
- 生産：固定費用200、可変費用80Q＋20Q²、価格240。0〜6個の比較で利潤最大は4個。
- GDP：一つの財、固定基準価格300円の学習例。実際の連鎖方式GDP統計そのものではない。
- 貯蓄：C＝a＋0.8Y、Y＝C＋I。政府・海外を省略し、価格一定、余剰生産能力あり、短期の数量調整を仮定する。投資を固定した場合と同時に増えた場合を比較する。
- 実質金利：名目金利を1％に固定。予想物価上昇率が−1％なら約2％、＋1％なら約0％。実際の特定期間の金利や政策効果の推計ではなく、近似計算の例。
- 政策比較：A地域100→110、B地域100→106の架空指数。前後差10から比較地域の変化6を引くと4。政策効果と解釈できる条件を併記する。
