# 進化生物学入門：構成と編集方針

更新日：2026-09-14。

## 3部構成

ユーザー指定の3部構成を教材の骨格とする。第2部の「どうやって現代にたどり着いたか？」は、学問の歴史を扱う見出し「進化生物学の成立と発展」とする。

1. **前提（現代的な解釈）**：進化の定義、遺伝、自然選択・浮動などの過程、種分化、行動を説明する水準、証拠。現在の理解を先に見渡せる入口。
2. **進化生物学の成立と発展**：年代・研究者・理論や発見の要点を縦の年表でたどる。詳しい背景や文献は、各項目の閉じたdetailsで読む。
3. **進化生物学とデザイン**：人間の行動を理解する視点、美と性選択の仮説、蘆澤雄亮の考察、デザインとの関係。

本編の目的は進化生物学そのものを学ぶこと。蘆澤の記事にある独自の欲求解釈やデザインへの接続は、第3部の考察として扱う。記事を補足扱いすることを理由に、学問の歴史的展開まで削除しない。

## 歴史の流れ

- ラマルク以前・以後の問題意識：種は変わるのか、何によって変わるのか。
- ダーウィンとウォレス（1858）、『種の起源』（1859）、性選択の詳論（1871）。
- メンデルの報告（1865）と論文刊行（1866）、1900年前後の再評価。
- フィッシャー（1918）、ホールデン、ライト（1931）らの集団遺伝学と、1930〜1940年代の総合説。
- DNAによる形質転換（1944）、二重らせん構造（1953）、木村の中立説（1968）、太田のほぼ中立な変異の議論（1973）。
- 並行して進んだ社会行動の研究：ウィン＝エドワーズ（1962）、メイナード＝スミス（1964）、ウィリアムズ（1966）、ハミルトン（1964）。
- トリヴァース（1971）、ドーキンス（1976）。
- ティンバーゲンの問いの整理（1963）、適応主義への批判（1979）、外適応（1982）。
- マルチレベル選択と血縁選択の関係、発生・ゲノムなどへの広がり。

年表では、上記の話題を発表・研究の年代順に並べる。ティンバーゲン（1963）、ハミルトン（1964）、木村（1968）、トリヴァース（1971）、太田（1973）なども、分野をまたいで同じ時間軸に置く。詳説と文献、補足の図や数値例は各項目に保持する。

年表示側には「自然選択（淘汰）の登場」「遺伝の法則の発見」などの短いポイントを添え、その列だけでも学問の展開を追えるようにする。メンデル以前にも遺伝という考えはあるため「遺伝という概念の誕生」とはしない。性選択は1859年に言及があるため、1871年のポイントは「性選択（淘汰）の展開」とする。

名称や出来事の列挙にとどめず、「何が未解決だったか」「どの知見をどう結びつけたか」を、閉じた状態でも読める各項目の説明に書く。集団遺伝学と群選択、遺伝物質としてのDNAと血縁選択は同義語ではない。前者の知見が後者の説明にどう関わるかを示す。

年表の前に、線に関係を書いた図を置く。「自然選択と遺伝」「DNAと分子進化」「遺伝と血縁選択」「群選択と血縁選択」の4つを切り替えられ、各項目から年表の該当箇所へ移れるようにする。線は単なる年代順を表さない。血縁選択とマルチレベル選択の関係は破線の両矢印で示し、後者が前者を置き換えたとは読ませない。

複数の研究の流れは並行しており、年順にすべてが置き換わったとは書かない。現代のマルチレベル選択を血縁選択の全面的な後継や最終回答として扱わない。2007年はウィルソンらの論考の発表年であり、マルチレベル選択の成立年として扱わない。

## 史実と説明の注意

- 性選択は『種の起源』1859年初版に記述がある。改版で初めて追加されたとはしない。
- メンデルの報告年と刊行年を区別する。
- 1953年はDNAそのものの発見年ではなく、二重らせん構造の解明の年として扱う。Franklin & Goslingの研究も併記する。
- 細菌との共生を、血縁選択の反証とはしない。相互利益と、生物学的な利他を区別する。
- 現在の機能、歴史的由来、いまの動機、発達の過程を混同しない。
- 蘆澤の考察と、教科書・原論文で説明される知見の位置づけを本文中で明示する。

## 図と計算

- 第1部：自然選択のモデルは閉じた補足で操作。単倍体／無性生殖の2型、Bの相対適応度は1。`p′ = p*wA / (p*wA + (1-p))`。突然変異・浮動・移住は含めない。
- 第1部：3種の系統樹は共通祖先との関係を示す模式図。枝長に時間の意味を持たせない。
- 第2部：ハミルトンのルールの図は閉じた補足。`r*b-c` の符号を比較。利益と費用は同じ適応度尺度の加算的な例。
- 第2部：マルチレベル選択は、集団内で80%→70%、20%→10%となっても全体では50%→58%となる数値例。実測データではない。

図は `learning/src/EvolutionExplorers.jsx`、計算は `learning/src/evolutionMath.js`。
