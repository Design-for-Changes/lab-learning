このガイドでは、研究室の配布テンプレートを使い、論文を編集可能なデータと提出用PDFに仕上げます。最初に短い試作をつくり、操作を確かめてから本文全体を組んでください。
**操作手順の確認：2026年9月11日。** Adobeのデスクトップ版ヘルプを参照しています。Wordの章はMicrosoftの案内を参照しています。メニュー名はOS・バージョンで一部異なります。
<callout>
**提出条件は、配布テンプレートと当年度の指示で確認してください。** 用紙サイズ、余白、文字サイズ、ページ数、ファイル名、PDFの指定は提出先によって異なります。このガイドでは共通の操作を説明します。
</callout>
論文の論理構成や文章表現は、[研究ガイドの「論文を書く」](RESEARCH_URLwriting/)へ。

## 1. 準備する
### 最初にそろえるもの
1. InDesignを起動できる環境と、学部・修士それぞれの最新の配布テンプレートを用意します。
2. 提出要領を読み、サイズ・余白・書体・ページ数・PDF設定・締切をメモします。
3. 本文の原稿、図表の元データ、参考文献の記録を集めます。文献には著者・題名・発行年・掲載先・ページ・DOIやURLを記録し、提出先の書式に整えます。
4. テンプレートの原本を保管し、作業用のコピーを作ります。フォント不足などの警告は、本文を流し込む前に確認します。
**研究室の資料**：[各種フォーマット・素材](https://app.notion.com/p/3e8b281ba95d4705a8f8f899725e195a)／[学部論文フォーマット ZIP](https://app.notion.com/p/3d7c22284dd181b59ddcd669bbfbc157#75cc22284dd1821dab8f01e1e2c710b0)／[修士論文フォーマット ZIP](https://app.notion.com/p/3d7c22284dd181b59ddcd669bbfbc157#1a7c22284dd18235b03281d61b47de7a)。[教員作成の論文体裁ガイド（PDF）](https://app.notion.com/p/3d7c22284dd181b59ddcd669bbfbc157#50ec22284dd183248e3b810c98d7804c)も参照できます。添付資料はNotionで開きます。利用する前に、その年度に指定された版か確認してください。
### ファイルの役割を区別する
<div class="file-map"><div><strong>.indb</strong><span>ブック：章の並びと参照先をまとめる</span></div><div><strong>.indd</strong><span>ドキュメント：章の本文・図表を編集する</span></div><div><strong>画像・図表</strong><span>配置した元ファイル：リンク先として保管する</span></div></div>
**ブックは、章の本文そのものを収めたファイルではありません。** `.indb`だけを別の場所へ送っても、参照している`.indd`や図表がそろうとは限りません。ひとつの作業フォルダーに章ファイルと素材をまとめ、移動・改名するときはリンクも確認します。
テンプレートが1つの`.indd`で構成されている場合は、そのまま単一ドキュメントとして作業できます。章別のファイルが配布されている場合に、ブックを使います。
**公式手順**：[ブックファイルの作成・保存](https://helpx.adobe.com/indesign/desktop/create-and-organize-pages/create-and-manage-book-files/create-save-book-files.html)、[ブックへのドキュメント追加](https://helpx.adobe.com/jp/indesign/desktop/create-and-organize-pages/create-and-manage-book-files/add-documents-to-book-files.html)。
### 作業するファイルを開く
1. 作業用コピーの`.indb`を開きます。ブックパネルに、表紙・目次・各章などのファイルが並びます。
2. 編集する章の`.indd`を開き、ページ、段落スタイル、リンクの各パネルを確認します。
3. 名前だけで判断せず、作業用フォルダー内のファイルを開いていることを確かめます。
4. 開始前の状態を保存します。日付や版番号を付けた区切りのコピーと、普段の上書き保存を使い分けてください。
### まず2ページで試す
いきなり全原稿を流し込まず、見出し1つ・本文2段落・図1点・キャプションを含む短い試作をつくります。以降の章を使って段落スタイル、ページ番号、画像の配置を試し、PDFを1度出力してください。
<callout>
**ここまでの確認**：どのファイルを編集するか説明できる。テンプレートの原本が残っている。試作PDFとInDesign画面を見比べ、文字や図の欠落がない。
</callout>

## 2. 本文・章・ページを編集する
### 段落スタイルで本文と見出しを揃える
1. 文字ツールで、書式を設定する段落内にカーソルを置きます。
2. **ウィンドウ → スタイル → 段落スタイル**を開き、テンプレートの「本文」「章見出し」など、その役割に合うスタイルを選びます。実際の名前は配布ファイルで確認します。
3. 同じ役割の段落に同じスタイルを適用します。太字やサイズの手動変更だけで見出しを作ると、自動目次で拾えないことがあります。
4. 一部の文字の強調には、必要に応じて文字スタイルを使います。段落スタイルの定義を変更すると、そのスタイルを使うほかの箇所にも影響するため、変更範囲を確認します。
**公式手順**：[段落スタイルと文字スタイル](https://helpx.adobe.com/jp/indesign/desktop/format-and-style-text/text-styles/create-and-edit-text-styles.html)。
### 親ページを確認する
**親ページ**は、ページ番号・柱・共通の枠などをまとめた雛形です。古い資料では「マスターページ」と呼ばれることがあります。
1. **ウィンドウ → ページ**を開きます。
2. テンプレートにある親ページと、本文ページへの適用状況を確認します。
3. 新しいページにも同じ雛形が必要なら、親ページを対象ページへドラッグして適用します。
4. 本文を編集するときは、通常のドキュメントページに戻ります。共通要素を直す必要があるときに親ページを編集し、適用先全体を見直します。
**公式手順**：[親ページの作成と適用](https://helpx.adobe.com/jp/indesign/desktop/create-and-organize-pages/create-and-manage-parent-pages/create-parent-pages.html)。
### 文字が次のページへ続くようにする
テキストは「テキストフレーム」という枠に入ります。連結した枠では、前の枠に入りきらない文章が次の枠へ流れます。
1. 既存の本文フレームに、短い原稿を入力または配置します。
2. 文章が枠に収まらず、出力ポートに**赤い＋**が出ていないか確認します。これはオーバーセットテキストの印です。
3. 続きのページとフレームを用意し、前のフレームの出力ポートをクリックして、続きのフレームをクリックします。
4. 前のページに文章を1段落追加し、後ろへ自然に流れることを確認します。枠の外で見えなくなっている文章がないかも確認します。
**公式手順**：[テキストフレームの連結](https://helpx.adobe.com/jp/indesign/desktop/add-and-manage-text/add-and-import-text/thread-text-frames.html)。
### 章を増やす
章別のブック構成では、**章のドキュメント`.indd`**を追加します。
1. 構成の近い章の`.indd`を作業用コピーとして複製するか、テンプレートに沿った新規ドキュメントを作ります。
2. ファイル名を変更し、複製した本文・題目・図表を新しい章の内容に置き換えます。
3. `.indb`を開き、ブックパネルのメニューから**ドキュメントを追加**を選び、新しい`.indd`を登録します。
4. ブック内の順番を整え、章番号・ページ番号・目次を確認します。複製元の開始番号や参照が残っていないか確認してください。
**公式手順**：[ブックへのドキュメント追加](https://helpx.adobe.com/jp/indesign/desktop/create-and-organize-pages/create-and-manage-book-files/add-documents-to-book-files.html)。
### 複数の章の書式を同期する
ブックの同期は、基準にしたドキュメントから、スタイルや親ページなどを他の章へ反映する操作です。
1. 基準として使う章をブックパネルで**スタイルソース**に指定します。
2. **同期オプション**で、揃える項目を確認します。章固有の親ページなどを上書きしてよいか、実行前に判断します。
3. 対象の章を選んで同期し、見出し・本文・ページ番号の見た目を確認して保存します。
**公式手順**：[ブックドキュメントの同期](https://helpx.adobe.com/jp/indesign/desktop/create-and-organize-pages/create-and-manage-book-files/sync-documents-books.html)。
<callout>
**ここまでの確認**：同じ階層の見出しに同じスタイルが使われている。追加した章がブックに入っている。文章の続きを含め、赤い＋が残っていない。
</callout>

## 3. 目次・図表を整える
### 図を配置し、元ファイルを管理する
1. 図表の元データを作業フォルダーに保存します。軸名・単位・凡例を、論文に置く大きさで読めるように整えます。
2. **ファイル → 配置**でファイルを選び、ページ上に配置します。更新する図は、元データとの関係を管理できるようリンクとして扱います。
3. 枠と画像の違いに注意し、縦横比や必要な部分を保ってサイズ・位置を調整します。
4. **ウィンドウ → リンク**で、使用中のファイルと状態を確認します。元データを変更したらリンクを更新します。
図を入れる時期は、論文の構成や作業方法に合わせて決めます。本文と対応する図を早めに置くと、説明の不足や必要なサイズも検討できます。
**公式手順**：[画像の配置](https://helpx.adobe.com/jp/indesign/desktop/add-graphics-and-media/add-edit-graphics/add-images.html)、[リンクパネル](https://helpx.adobe.com/jp/indesign/desktop/add-graphics-and-media/manage-links/links-panel-overview.html)。
### 図表番号・説明・本文の参照を揃える
各図表に、テンプレートの指定に沿った番号とキャプションを付けます。番号は、本文中の「図○」「表○」と対応させてください。並べ替えた後には、番号・本文の参照・掲載順をまとめて確認します。
図は「何を示し、どこを見るとよいか」が分かるように、表は単位や条件が分かるようにします。見出し、キャプション、本文で同じ情報を無意味に重ねず、それぞれの役割を決めます。
**確認すること**：文字が読める、比較の尺度が揃っている、説明と図表が一致する、引用した図表の出典が示されている。
### ページ番号を自動で表示する
1. ページパネルで、番号を置く親ページを開きます。
2. 番号用のテキストフレームにカーソルを置き、**書式 → 特殊文字を挿入 → マーカー → 現在のページ番号**を選びます。
3. 親ページでは識別用の文字、本文ページでは実際のページ番号が表示されることを確認します。見開きなら左右両方を確認します。
4. 表紙・目次・本文で番号の開始や形式を分ける場合は、**ページ番号とセクションの設定**を確認します。ブックの章を追加した後にも、番号が途中で戻っていないか確認します。
**公式手順**：[自動ページ番号とセクション](https://helpx.adobe.com/jp/indesign/desktop/create-and-organize-pages/page-numbers-chapters-and-sections/add-page-numbers-and-markers.html)。
### 見出しから目次を作成・更新する
1. 目次に載せたい見出しへ、適切な段落スタイルを適用します。
2. 目次用のページを開き、**レイアウト → 目次**で、収集する段落スタイルと、目次側の見た目・ページ番号の表示を設定します。
3. ブック全体の目次を作る場合は、目次用ドキュメントをブックに含め、対象がブック全体になるよう設定します。
4. 生成した目次を、本文と独立したテキストフレームに配置します。
5. 見出しやページ構成を変更したら、既存の目次内にカーソルを置き、**レイアウト → 目次を更新**を実行します。生成済みの目次だけを手で書き換えても、元の見出しは直りません。
**公式手順**：[目次の生成と更新](https://helpx.adobe.com/indesign/desktop/indexes-and-references/add-a-table-of-contents/generate-maintain-tocs.html)、[目次スタイルの設定](https://helpx.adobe.com/jp/indesign/desktop/indexes-and-references/add-a-table-of-contents/customize-toc-style.html)。
<callout>
**ここまでの確認**：本文の見出し・目次・ページ番号が一致している。図表の入れ替え後にも、本文の参照とキャプションが一致している。
</callout>

## 4. PDFを書き出す
### 書き出す前にプリフライトを確認する
**ウィンドウ → 出力 → プリフライト**を開き、問題のあるページや項目に移動して修正します。少なくとも、見つからないフォント、リンクの不明・変更、オーバーセットを確認してください。
プリフライトが何を検査するかはプロファイルで変わります。「エラーなし」だけで、内容・画質・提出条件のすべてを満たしたとは判断できません。全ページを対象にしているか、必要な検査項目が含まれているかを確認します。
**公式手順**：[プリフライトパネルの設定と使用](https://helpx.adobe.com/jp/indesign/desktop/print/preflight/configure-and-use-the-preflight-panel.html)。
### 論文全体をPDFにする
1. 章ファイルを保存し、ブックの並びとページ番号、目次を確認します。
2. ブック全体なら、ブックパネルのメニューから**ブックをPDFに書き出し**を選びます。一部の章だけが対象になっていないか確認します。
3. ひとつの`.indd`だけを出力する場合は、**ファイル → 書き出し**を使います。
4. 通常の論文PDFでは**Adobe PDF（プリント）**を選び、提出先の指定に合うプリセット・設定にします。出力する範囲、ページ単位か見開きか、圧縮や裁ち落としの指定を確認して書き出します。
**公式手順**：[ブックのPDF書き出し](https://helpx.adobe.com/uk/indesign/desktop/print/print-production-and-file-creation/print-or-export-book-files.html)、[用途に応じたPDF設定](https://www.adobe.com/jp/learn/indesign/web/export-settings-pdf-and-print)。
### 出来上がったPDFを開いて確認する
- 表紙・目次・本文・参考文献・付録が、意図した順番とページ数で入っている。
- 目次のページ番号と本文の該当ページが一致している。
- 文字の欠け、置き換わった書体、見えなくなった数式がない。
- 図表の細い線・軸名・凡例が読める。拡大表示だけでなく、実際に読む大きさでも確認する。
- 意図しない空白ページや見開き出力がない。提出用のファイル名と容量に合っている。
修正した場合は再出力し、**最後に提出するファイルそのもの**を開いて確かめます。容量を下げる必要がある場合も、圧縮後に図表や小さな文字を確認してください。
### 編集用データを引き継げる形で残す
`.indd`だけでなく、元の図表とリンク関係も残します。単一ドキュメントは**ファイル → パッケージ**で関連ファイルをまとめられます。ブック構成では、全章の`.indd`・`.indb`・素材がそろっているか確認してください。
Adobe Fontsで有効化したフォントは、通常のファイルコピーと同じようには同梱されません。編集する人の環境で必要なフォントを使えることを確認し、仕上がりの参照用PDFも残します。
**公式手順**：[ファイルのパッケージ化](https://helpx.adobe.com/indesign/desktop/print/preflight/package-files-for-output.html)、[フォントのパッケージに関する案内](https://helpx.adobe.com/fonts/web/getting-and-using-fonts/package-font-files.html)。
<callout>
**ここまでの確認**：提出PDFを全ページ確認した。編集用データと素材を保管した。古い出力と提出する最新版を見分けられる。
</callout>

## 5. 困ったとき
### 赤い＋が出る・文章が途中で消える
赤い＋は、枠に入りきらないテキストがある印です。まず本文フレームの連結を確認し、必要なページや枠を追加します。文字サイズを小さくして隠す前に、途中の連結や枠の大きさ、段落の設定を確認してください。
対処後は、プリフライトと本文末尾の両方で、文章が欠けていないことを確認します。[本文とテキストフレームの手順へ](INDESIGN_URLediting/)。
### フォントが見つからない・改行が変わる
警告に表示されたフォント名を記録し、テンプレートが指定する書体を確認します。代替フォントへ変更すると行末やページ数も変わるので、本文・目次・図表位置を再点検します。
共同編集では、InDesignのバージョンと使用フォントを共有しておきます。原因が分からない場合は、警告内容と、いつから変わったかを添えて相談してください。
### 画像が粗い・リンク切れになる
1. **ウィンドウ → リンク**で、不明なリンクや変更済みの素材を確認します。移動した素材は正しい元ファイルへ再リンクします。
2. 画面だけが粗い場合は、**表示 → 表示画質 → 高品質表示**を試し、書き出したPDFと見比べます。
3. PDFも粗い場合は、元画像と配置サイズを確認します。リンク情報の**実効PPI**は、配置した大きさでの解像度です。大きく引き伸ばしていないか、圧縮しすぎていないか確認します。
**公式手順**：[リンクパネル](https://helpx.adobe.com/jp/indesign/desktop/add-graphics-and-media/manage-links/links-panel-overview.html)、[画像の粗い表示への対処](https://helpx.adobe.com/jp/indesign/desktop/troubleshoot/file-and-output-issues/pixelated-graphics.html)。
### 目次に見出しが出ない・番号が合わない
順に、見出しに適用した段落スタイル、目次に含めるスタイル、対象のブック、章の並びと開始番号を確認します。その後で目次を更新します。目次のフレーム自体にオーバーセットがないかも確認してください。
本文中の文字を大きくしただけでは、設定した見出しスタイルと一致しないことがあります。[目次・ページ番号の手順へ](INDESIGN_URLfigures/)。
### PDFに一部の章しか入らない
ブックに必要な章が登録されているか、出力時に「選択したドキュメント」だけを対象にしていなかったか確認します。書き出す範囲とページ数を確認して再出力してください。[PDF書き出しの手順へ](INDESIGN_URLexport/)。

## 6. 先輩の論文を探す
### 研究室の資料から探す
[研究系統図＋論文倉庫（Notion）](https://app.notion.com/p/7c651467e68c454d8ee52b812e620269)から、近いテーマ・手法の論文や梗概を探します。ファイルの閲覧には研究室のアクセス権が必要な場合があります。
完成例は、何をどの順に説明しているかを学ぶために使います。過去の論文の体裁が、そのまま今年の提出要領に合うとは限らないため、書式は当年度の指定と照合してください。
### 図書館から探す
[芝浦工業大学図書館](https://lib.shibaura-it.ac.jp/)の検索・電子資料の案内から探します。著者名、題目、年度が分かると検索しやすくなります。
閲覧できる資料、本文の公開範囲、学外からの利用方法は、図書館側の現在の案内に従ってください。見つからない場合は書誌情報を控え、図書館や指導教員に確認します。
### 参考にするときの読み方
1. 目次を見て、問い・方法・結果・考察がどの順に配置されているか書き出します。
2. 図表を1点選び、本文で何を説明するために使われているかを確認します。
3. 自分の論文に取り入れたい構成と、その理由をメモします。文章や図を使う場合には、出典と引用箇所が分かる形にします。

## 7. Wordで梗概をつくる
### 配布書式で短い試作をつくる
梗概用のテンプレートをコピーし、題目・著者情報・本文・図1点を入れて試します。用紙、余白、段組、文字サイズ、行間は当年度の指定を確認します。
文字が収まらないときは、まず内容の重複や図表の配置を見直します。規定を確認せず、固定値の行間を変更したり、行グリッドとの対応を解除したりしないでください。
### 編集記号で段落と空白を見る
**ホーム**タブの段落の表示／非表示ボタンを使い、段落記号・空白・タブを表示します。改行、段落の区切り、空白の連打を区別し、配置のずれを確かめます。
見出しや本文にはテンプレートのスタイルを使い、位置合わせには段落設定やタブを使います。空白を大量に入れて位置を合わせると、書体や編集内容が変わったときに崩れやすくなります。
**公式手順**：[Wordの編集記号の表示](https://support.microsoft.com/ja-jp/word/show-or-hide-tab-marks-in-word)。
### 図とキャプションを配置する
1. 図を挿入し、まず**行内**の配置で、段落とともに移動する状態を試します。
2. 回り込みが必要な場合は、図の**レイアウトオプション**から配置方法を選びます。本文を増減したときにも、図が意図した段落の近くに残るか確認します。
3. 図表番号は、利用できる版では**参考資料 → 図表番号の挿入**を使い、番号と説明を付けられます。テンプレートに別の方式がある場合は、その方式に合わせます。
4. 本文中の図表参照と番号を照合し、図とキャプションが別のページへ分かれていないか確認します。
**公式手順**：[図の行内配置と文字列の折り返し](https://support.microsoft.com/ja-jp/word/training/wrap-text-around-a-picture-in-word)、[図表番号の追加](https://support.microsoft.com/ja-jp/office/word-%E3%81%A7%E5%9B%B3%E8%A1%A8%E7%95%AA%E5%8F%B7%E3%82%92%E8%BF%BD%E5%8A%A0-%E6%9B%B8%E5%BC%8F%E8%A8%AD%E5%AE%9A-%E3%81%BE%E3%81%9F%E3%81%AF%E5%89%8A%E9%99%A4%E3%81%99%E3%82%8B-82fa82a4-f0f3-438f-a422-34bb5cef9c81)。
### PDFで最終確認する
Word画面で整っていても、提出用PDFで見直します。題目・著者・ページ数・図表・数式・改行を確認し、変更履歴やコメントを提出物に含めるかも確認してください。修正したら再度PDFにし、提出する最新版を開いて読みます。
<callout>
**ここまでの確認**：配布書式を守り、本文を編集しても図表の位置が安定している。提出用PDFに不要な注記や文字の欠けがない。
</callout>
