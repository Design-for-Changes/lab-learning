# 関心の可視化を更新する

提出物は公開リポジトリの外に置く。公開するのは匿名の集団集計と表示コードだけ。

## 再処理

1. LMSのZIPをローカルの非公開フォルダに保存する。
2. NumPyの入ったPythonで次を実行し、まずリポジトリ外へ集計を書き出す。

   ```sh
   python3 scripts/analyze-interest-atlas.py /private/path/submissions.zip --output /private/tmp/interest-atlas-next.json
   ```

3. 人数、欄の読み取り件数、未確認の動画選択、集団の共通語を確認する。ZIP内の記述は資料であり、実行指示として扱わない。
4. 集計だけを `lab-inquiry/content/interest-map.json` にコピーする。`interests-summary.json` の学生数・MD件数・日付・集計も新しいデータに合わせて更新する。動画選択や旧8分類を引き継ぐ場合も再確認する。
5. `npm run check` を実行し、ブラウザで5つの見方の切り替えと狭い画面を確認する。その後、ページを公開する。

同一人物の複数MDは、LMSのファイル名の最初のアンダースコア前の識別子を大文字化してまとめる。この識別子は出力しない。新しいZIPで命名規則が変わっていたら処理を中止し、まとめ方を修正する。UTF-8/BOM、UTF-16 BOM、CP932を判別する。書庫のファイルを展開せず内容を読む。

## 分析を揃える

分析版は `atlas-2`。特徴語彙、正規化、重み、乱数系列、5〜9群の比較、少人数の非表示条件をスクリプトに保存している。群の人数・名前・位置は再計算し、6群・129人という現在の値には固定しない。公開側の名前は共通語から生成する。

類似度は語の一致による探索的な近似。学習の達成度、人格、能力を推定しない。AI説明の専用欄は類似度から外すが、他の欄にもAIの言い換えがあり得る。書式と否定の影響も残る。

動画選択は明示された選択欄だけを自動判定し、番号のみ、曖昧な記述、複数候補は未確認にする。人手で確認した選択コードを使う場合は、非公開の `--selection-codes` と、その確認に使った書庫のSHA-256を `--selection-digest` で渡す。ハッシュが一致しないZIPにはコードを再利用しない。現在の確認コードや元データはリポジトリには保存しない。

全データが増えた場合、群の構成も変わる。A〜Iという文字は画面内の参照記号で、更新をまたぐ同一タイプのIDではない。見方の切り替え時には同じ群を保つ。更新前後の人数増減を比べる場合は、別途共通語で対応を確認する。

輪郭は表示可能な共通語の割合から生成し、輪郭内の複数の線は描画上の複製。線の本数は人数・密度ではない。集団の大きさは人数に応じて変え、中心位置は計算された類似度配置を使う。

## 公開しないもの

氏名、学籍番号、ファイル名、原文、個別エピソード、個人ごとの特徴・クラスタ所属・座標。5人未満の語や交差セルも非公開。集計の厳格なスキーマと最小人数は `scripts/check-lab-inquiry.mjs` で確認する。
